# Локальное хранилище: Drift Database

Документация описывает архитектуру локальной базы данных, построенную на базе пакета `drift`.

## Ключевые компоненты

### 1. AppDatabase (Implementation)
**Путь:** `lib/core/local_storage/src/database/app_database.dart`
*   **Роль**: Центральный класс базы данных.
*   **Ответственность**: 
    *   Регистрация таблиц базы данных (параметр `tables`).
    *   Управление подключением к SQLite через `drift_flutter`.
    *   Обработка миграций схем при обновлении приложения.
    *   Конфигурация специфичных параметров SQLite (например, `foreign_keys`).

### 2. Подключение (Connection)
*   **Механизм**: Используется пакет `drift_flutter` для автоматического определения пути к базе данных в зависимости от платформы (iOS, Android, macOS).
*   **Файл БД**: По умолчанию файл базы данных сохраняется под именем `app_database.sqlite`.

### 3. Регистрация в DI
*   **Область видимости**: `AppDatabase` зарегистрирован как `@singleton`.
*   **Назначение**: Гарантирует наличие только одного активного подключения к базе данных на протяжении всего жизненного цикла приложения, предотвращая ошибки совместного доступа.

## Правила расширения

При добавлении новых сущностей или изменении схемы:
1.  **Создание**: Описать класс таблицы в соответствующей фиче или в `core`.
2.  **Регистрация**: Добавить класс таблицы в список `tables` в `AppDatabase`.
3.  **Генерация**: Запустить генерацию кода: `dart run build_runner build`.
4.  **Миграция**: При изменении структуры существующих таблиц:
    *   Инкрементировать `schemaVersion`.
    *   Описать логику трансформации данных в методе `onUpgrade` класса `AppDatabase`.

## Технические аспекты
*   **Целостность данных**: Поддержка внешних ключей (`PRAGMA foreign_keys = ON`) включена по умолчанию для обеспечения ссылочной целостности.
*   **Типизация**: Использование генерации кода обеспечивает строгую типизацию всех SQL-запросов и возвращаемых данных.
*   **Отладка**: Возможность настройки логирования SQL-запросов через кастомный `QueryExecutor` для dev-окружения.
