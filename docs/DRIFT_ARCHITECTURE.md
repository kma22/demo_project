# Локальное хранилище: Drift

## Компоненты

### AppDatabase

**Путь:** `lib/core/local_storage/src/database/app_database.dart`

Центральный класс базы данных:
- Регистрация таблиц (параметр `tables`)
- Подключение к SQLite через `drift_flutter` (автоопределение пути по платформе)
- Миграции схемы при обновлении
- `PRAGMA foreign_keys = ON` для ссылочной целостности

Зарегистрирован как `@singleton` -- одно подключение на весь жизненный цикл приложения.

Файл БД: `app_database.sqlite`.

---

## Правила расширения

При добавлении новых таблиц или изменении схемы:

1. Описать класс таблицы в соответствующем модуле (фича или core)
2. Добавить класс в список `tables` в `AppDatabase`
3. Запустить `dart run build_runner build`
4. При изменении существующих таблиц:
   - Инкрементировать `schemaVersion`
   - Описать трансформацию данных в `onUpgrade`

## Технические детали

- **Типизация**: кодогенерация обеспечивает строгую типизацию SQL-запросов и возвращаемых данных
- **Отладка**: настройка логирования SQL через кастомный `QueryExecutor` для dev-окружения
